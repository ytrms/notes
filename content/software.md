List of software I use and can wholeheartedly recommend you.
# Essentials
| Name                                                               | Platform        | Description                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------ | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Raycast](https://raycast.com)<br>                                 | macOS, Windows  | App that starts when you press a keyboard shortcut, letting you launch applications, run scripts, and much much more. It just makes your computer better.                                                                                                            |
| [Obsidian](https://obsidian.md)                                    | All             | It's where I take my personal notes. The website you're on right now is actually published through Obsidian. I even made a few YouTube videos about it, including a guide for absolute beginners. Link's in the footer for that.                                     |
| [AltTab](https://alt-tab-macos.netlify.app/)                       | macOS           | Brings a proper Alt-Tab (well, ⌘-tab) to macOS.                                                                                                                                                                                                                      |
| [Homebrew](https://brew.sh)                                        | macOS, Linux    | My favorite way to install software on macOS. Well, my second favorite actually – the first would be the Nix package manager. But that's not for the faint of heart.                                                                                                 |
| [Maccy](https://maccy.app)                                         | macOS           | Best clipboard manager I have found so far. Free and lightweight (unlike Paste).                                                                                                                                                                                     |
| [Shottr](https://shottr.cc)                                        | macOS           | Screenshot utility. Not as featureful as, say, CleanShot X, but much more lightweight. Or at least it feels that way.                                                                                                                                                |
| [Ghostty](https://ghostty.org)<br>                                 | macOS, Linux    | The one and only terminal app. Fast, featureful, often updated, good-looking. No need to look anywhere else.                                                                                                                                                         |
| [Little Snitch](https://obdev.at/products/littlesnitch/index.html) | macOS           | Firewall you can install on your Mac. The main thing is that it has lists of known trackers, and it blocks those at the system level. You can also allow/deny manually of course. The Window version of this would be NetLimiter.                                    |
| [IINA](https://iina.io)                                            | macOS           | The media player for macOS. Basically a more "beautiful" and easy to use version of mpv, which is the actual goat player.                                                                                                                                            |
| [AlDente](https://apphousekitchen.com/aldente-overview/)           | macOS           | Advanced battery manager for macOS with a ton of functionality, graphs, etc. Good for battery health (I think).                                                                                                                                                      |
| [Overcast](https://overcast.fm)                                    | macOS, iOS, Web | My favorite podcast player. I've been using it for 10+ years. Its best feature is the "smart silence" one, where it automatically speeds up small silences smoothly as you listen. Apparently, it saved me over 80 hours so far just from those small optimizations. |
| [Figma](https://figma.com)                                         | Web             | Need I say anything else?                                                                                                                                                                                                                                            |
# Things I use often

| Name                                                                 | Platform     | Description                                                                                                                                                    |
| -------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Taskbar](https://lawand.io/taskbar/)                                | macOS        | Windows-style taskbar for macOS. It always stays open at the bottom, just like the Windows taskbar. I find it most useful for work, where I have tons of tabs. |
| [WizTree](https://diskanalyzer.com/)                                 | Windows      | Fast disk usage analyzer. Great to understand what's taking up space.                                                                                          |
| [PearCleaner](https://github.com/alienator88/Pearcleaner)            | macOS        | Whenever you delete an application, it pops up helping you delete that app's stray files.                                                                      |
| [Neovim](https://neovim.io)                                          | All          | *The* text editor. Learning Vim keybindings will change you. Pair it with [LazyVim](https://www.lazyvim.org/) and you're golden.                               |
| [Google Antigravity](https://antigravity.google)                     | All          | AI code editor with generous limits (more generous and capable than Cursor's free tier in my opinion.)                                                         |
| [btop](https://github.com/aristocratos/btop)                         | macOS, Linux | The coolest "task manager" / "resource usage viewer" for the terminal.                                                                                         |
| [Screen Studio](https://screen.studio/)                              | macOS        | Fancy screen recorder for the Mac.                                                                                                                             |
| [Amphetamine](https://apps.apple.com/it/app/amphetamine/id937984704) | macOS        | Keeps your screen and Mac awake when you need it.                                                                                                              |
| [Calibre](https://calibre-ebook.com/)                                | All          | Sadly the best book management software there is. Great to also send your ebooks to your reader, etc.                                                          |
| [Reeder](https://reederapp.com/)                                     | macOS, iOS   | The best RSS reader for the Apple ecosystem.                                                                                                                   |
| [Raindrop.io](https://raindrop.io)                                   | All          | The best bookmark collection software around.                                                                                                                  |

# Everything else (still great stuff!)
| Name                                                       | Platform       | Description                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [CloudMounter](https://cloudmounter.net)<br>               | macOS, Windows | Lets you mount remote storage locations to your computer as if they were a native part of your file system. For example, I have a local FTP 'server' at home I connect to using this.                                                                                             |
| [Rufus](https://rufus.ie)<br>                              | Windows        | The most stable way to create bootable USBs from Windows.                                                                                                                                                                                                                         |
| [caligula](https://github.com/ifd3f/caligula)<br>          | Linux          | ... and the same for Linux.                                                                                                                                                                                                                                                       |
| [Aerospace](https://github.com/nikitabobko/AeroSpace)      | macOS          | A tiling window manager for the Mac. Basically, it automatically tiles windows for you as you open them. It takes a while to get used to but for some people it can be a powerful way to organize your windows.                                                                   |
| [Komorebi](https://github.com/LGUG2Z/komorebi)             | Windows        | ... and the same for Windows.                                                                                                                                                                                                                                                     |
| [SunVox](https://warmplace.ru/soft/sunvox/)                | All            | Synthesizer + tracker to make music. Uses an interesting and innovative interface.                                                                                                                                                                                                |
| [hw-probe](https://github.com/linuxhw/hw-probe)            | Linux          | If you're thinking of switching to Linux, it's important to know whether or not your hardware is supported by the kernel. So, burn a Linux .iso into a USB and run this software from there. It will tell you if there's something not supported. It'll save you headaches later. |
| [SketchyBar](https://felixkratz.github.io/SketchyBar/)     | macOS          | A completely customizable and scriptable menu bar for the Mac. Some programming/tinkering experience recommended.                                                                                                                                                                 |
| [Cog](https://cog.losno.co/)                               | macOS          | Free, open source, and lightweight music player for the Mac. For more basic needs, just use mpv or IINA though.                                                                                                                                                                   |
| [JankyBorders](https://github.com/FelixKratz/JankyBorders) | macOS          | Adds a border around the currently active window. That's it. (minimal programming/tinkering experience required)                                                                                                                                                                  |
| [BGB Game Boy Debugging Emulator](https://bgb.bircd.org/)  | Windows        | Game Boy (Color) emulator focusing for those who are making games for it.                                                                                                                                                                                                         |
| [Foliate](https://johnfactotum.github.io/foliate/)         | Linux          | An ebook reader for Linux that looks and works great.                                                                                                                                                                                                                             |
| [Ollama](https://ollama.com/)                              | All            | Probably the best and easiest way to run LLMs locally.                                                                                                                                                                                                                            |
| [Kanshi](https://wiki.archlinux.org/title/Kanshi)<br>      | Linux          | It detects when monitors are plugged in/out and helps you output to them (only useful if you're using some esoteric window manager)                                                                                                                                               |
| [LocalSend](https://localsend.org/)                        | All, Web       | "AirDrop" for all devices. There's also [PairDrop](https://pairdrop.net) which looks nice.                                                                                                                                                                                        |
| [termscp](https://github.com/veeso/termscp)                | macOS, Linux   | Connect to ftp servers from the terminal.                                                                                                                                                                                                                                         |

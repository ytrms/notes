# Essentials
| Name                                         | Platform     | Description                                                                                                                                                                                       |
| -------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Raycast](https://raycast.com)<br>           | macOS        | App that starts when you press a keyboard shortcut, letting you launch applications, run scripts, and much much more.                                                                             |
| [Obsidian](https://obsidian.md)              | All          | It's where I take my personal notes. The website you're on right now is actually published through Obsidian. I even made a few YouTube videos about it, including a guide for absolute beginners. |
| [AltTab](https://alt-tab-macos.netlify.app/) | macOS        | Brings a proper Alt-Tab (well, ⌘-tab) to macOS.                                                                                                                                                   |
| [Homebrew](https://brew.sh)                  | macOS, Linux | My favorite way to install software on macOS.                                                                                                                                                     |
